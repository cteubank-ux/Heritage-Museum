4. JavaScript code defense

The script first selects the native .menu-button and the #primary-nav list. It checks that both elements exist before enhancing the page. Only then does it remove the button's hidden state, set data-enhanced="true" on the navigation landmark, and initialize the list with data-state="closed". This order preserves the native baseline: if JavaScript is unavailable, the button stays hidden and the list remains visible.

The named setMenuOpen(isOpen) function synchronizes two states: it updates the button's aria-expanded attribute to the string "true" or "false", and updates the list's data-state to "open" or "closed". CSS uses that data state to hide the list only in the enhanced narrow layout. The native button's click event toggles the state, so browser-native Enter and Space activation work without custom keyboard code.

A document-level keydown listener checks for the Escape key while the menu is open in the narrow layout. It calls setMenuOpen(false) and then button.focus(), closing the list and returning keyboard focus to its control. A wide-layout media query forces the list to display and hides the disclosure button, so a previous narrow state cannot hide the wide navigation.
